
A mobile app for posting classified ads, built with Flutter and using Supabase as the backend.

## 🚀 Features

- 📱 Cross-platform app (iOS and Android)
- 🔐 User authentication
- 📝 Creating and managing classified ads
- 🔍 Advanced search and filtering
- 📍 Regional filtering
- 💰 Support for multiple currencies
- 📸 Uploading and managing photos
- 💬 User-to-user chat
- ❤️ Saving listings to favorites
- 👤 User profile
- 🔔 Notification system
- 📊 Admin dashboard

## 🛠 Tech stack

- **Frontend**: Flutter
- **Backend**: Supabase
- **Database**: PostgreSQL
- **File storage**: Supabase Storage
- **Authentication**: Supabase Auth
- **Realtime**: Supabase Realtime
- **Search**: Algolia

## 📋 Requirements

- Flutter SDK
- Dart SDK
- Android Studio / VS Code
- Supabase CLI
- Git

### User Features
